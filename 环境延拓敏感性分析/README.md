# 4小时后环境延拓敏感性分析

## 分析目的

检查仅掌握前4小时环境观测时，4小时后的边界延拓假设会在多大程度上影响第三、四问的数值临界干燥时间。本分析不改主模型、物性关系、初始条件或第四问的附件2收缩曲线。

第四问的结果属于“给定收缩曲线条件下的边界情景分析”。

## 数据与统计口径

- 0–4 h：沿用附件环境观测及原线性插值。
- 末1小时统计范围：3–4 h，即10800–14400 s。
- 端点：两端均包含；使用每60 s一个的原观测点，共61个样本。
- 标准差：样本标准差（分母为 n-1）。
- 末小时温度均值：49.998934 °C；样本标准差：0.154353 °C。
- 末小时环境水分均值：0.049987541 kg/kg；样本标准差：0.000150129 kg/kg。
- 4 h末次观测：50.165000 °C、0.049860000 kg/kg。

S2、S3仅为人工组合的情景扰动，不代表实际发生概率、置信区间或严格最坏情况。

## 计算设置

- 第三问：固定半径径向网格，1281节点，Δr=0.0015625 cm。
- 第四问：归一化移动域，1280区间、1281节点；沿用同一条附件2收缩曲线。
- 两问均使用BDF，rtol=1e-9，atol=1e-11，最大时间步长60 s。
- 0–4 h先积分一次；以4 h状态作为四个情景的共同初值，再按各情景边界积分。
- 临界时间由全计算节点最大含水率从上向下穿越0.15的终止事件确定。
- 半径数据仅使用附件2的0–72 h范围；不在72 h外外推。
- 所有时间差均减去本次同网格、同容差、同初值重新计算的S0，不使用其他网格结果。

四个情景在两问中均于72 h内达到阈值，因此汇总表中的“72 h最大含水率”单元格留空，并由状态字段标明“达到阈值”。

## 简短结论

在本次基于末1小时均值和一个样本标准差构造的情景范围内，以下结论保持一致：四个情景均在72 h内达标；第四问的临界时间始终早于第三问；S0最快、S2最慢，S1和S3位于二者之间。

时间数值对延拓假设存在可见但不大的依赖。相对同配置S0，最慢的S2使第三问延长0.590104 h（约35.41 min，1.0319%），使第四问延长0.519178 h（约31.15 min，1.0215%）。S1分别延长约18.27 min和16.07 min；S3与S0非常接近，分别延长约1.25 min和1.09 min。因此，约51 h与57 h这一时间量级和两问先后关系较稳定，但精确到分钟的临界时间应注明所用的4小时后环境延拓规则。
