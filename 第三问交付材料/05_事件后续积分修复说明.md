# 第三问事件后续积分修复说明

## 修复内容

旧程序首次积分在阈值事件处终止，但随后仍用该终止解的连续插值函数计算 205860–206100 s 报表数据。这些时间超过了该解的有效积分终点 205821.742187 s，属于区间外外推。

修复程序采用两段积分：

1. 从 0 s 积分至首次阈值事件，保存临界时间和事件状态；
2. 以事件状态为初值，关闭终止事件，继续实际积分至候选报告时间；
3. 拼接两段真实积分解，只允许在各段覆盖范围内采样；
4. 在候选报告点检查全节点未舍入最大含水率。若不小于 0.14995，则每次顺延 60 s 并继续积分。

采样函数现在会拒绝有效积分区间外的时间、非有限时间和非有限位置。移动域调用可传入随时间变化的半径；仅对满足 `r≤R(t)` 的位置插值，域外位置保持空值，不填零。求解失败、连续解缺失、事件未触发或结果出现非有限值时，程序停止生成成功结果。

## 两个时间口径

- 数值临界时间：205821.742187 s，即 57.172706 h。此时全域最大含水率恰好到达 0.15 kg/kg，用于回答连续模型的首次达标边界。
- 保守报告时间：206100 s，即 57.25 h。该时刻经过事件后的真实续积分验证，全节点最大未舍入含水率为 0.149918566786 kg/kg，严格小于 0.14995，因此四位小数明确显示为 0.1499。

论文正文应报告数值临界时间，并说明竞赛附件和表 5 采用保守报告时间。二者不能混写为同一概念。

## 末五个时刻复核

对 205860、205920、205980、206040、206100 s 的 21 个径向位置逐项比较旧外推值与新续积分值，共 105 项。最大绝对差为 4.2773284914×10⁻¹¹ kg/kg，四位小数改变 0 项。数值接近不改变旧方法越界的事实；本次交付仍全部替换为真实续积分结果。

完整逐项记录见 `第三问末五行新旧对照.csv`。
